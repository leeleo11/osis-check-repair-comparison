# 验算修复线实验数据后处理

跑完后的 `runs/` 不进 Git。后处理只读其中已结束的 run，写出汇总，不把种错做法和 NG 真值放进表格说明以外的公开文件。

只统计同时能读到 `evaluation.json` 且 `manifest.json` 状态为 `completed` 或 `failed` 的目录。路径里带 `_archive` 的旧尝试跳过。

## 汇总

在仓库根目录执行：

```powershell
uv run python scripts/summarize_results.py `
  --runs-dir runs\formal-v1 `
  --output results\formal-v1
```

`results/` 已被忽略。输出两个文件：

| 文件 | 内容 |
| --- | --- |
| `summary.json` | 每个架构的条数、修复通过数、修复率，以及按桥型分开的同样三项 |
| `records.csv` | 每条 run 的架构、桥型、题号、状态、失败码、定位分、是否修复通过、耗时、目录 |

定位分来自 `evaluation.json` 的 `localization_score`。修复是否通过来自 `repair_pass`。失败的 run 仍留在条数里，修复率的分母包含它们。

这些文件只用于本地看结果。需要对外给表时，去掉 `run_dir` 再另存一份。
