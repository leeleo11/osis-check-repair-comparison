# 数据边界与发布审计

## 可以提交

- Python 源码、公开 schema、无答案 synthetic smoke。
- 单元测试、环境锁文件和复现文档。
- 只含占位路径的 example 配置。

## 不得提交

- 正式 samples、seed、reason code 真值、baseline/seeded NG、种错方式与答案路径。
- seeded 工程、候选工程、OSISPost、LCC、Check 和 Temperary 输出。
- 模型原文、trace、evaluation、manifest、汇总结果、日志和数据库。
- API key、token、个人目录与 local 配置。

## 发布门禁

执行：

    uv run python scripts/audit_public_boundary.py

审计读取 Git 已跟踪文件以及尚未忽略的新文件，检查私有目录、原生输出扩展、JSON 隐藏字段、凭据形态和机器绝对路径。失败时打印相对路径和规则，不自动删除。

随后检查：

    git status --short
    git ls-files

确认 runs、reports、tmp、data、datasets、seeded、private、candidate_project 和 local 配置未出现。

## 干净复现导出

export_repro_workspace.py 只复制 git ls-files 返回的文件，并在导出目录生成被忽略的 parent_repo.local.txt。它不会复制 .git、ignored run 或任何外部正式数据。
